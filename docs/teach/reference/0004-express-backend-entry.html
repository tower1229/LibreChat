层路径职责
入口 api/server/index.js 启动、全局中间件、挂载路由、SPA fallback、错误处理
路由表 api/server/routes/index.js 聚合各 feature 的 Router
Handler api/server/routes/*.js 薄包装：解析 req → 调服务 → res.json/send
业务逻辑 packages/api TypeScript 服务、中间件、工具（@librechat/api）
启动阶段（startServer，一次） connectDb → getAppConfig → 注册中间件 → 挂载路由 → listen → MCP / migrations → serverReady = true 请求阶段（每个 HTTP 请求） 全局中间件链 → 路由级中间件 → Router handler → 响应 未匹配 /api/* → apiNotFound 未匹配其他 → SPA index.html 抛错 → ErrorController
