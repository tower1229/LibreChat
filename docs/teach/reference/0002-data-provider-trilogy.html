文件职责二开时改什么
api-endpoints.ts 拼 URL（路径 + query） 新增/修改 REST 路径
types/ · config.ts 请求/响应 TypeScript 类型 新字段、新接口形状
data-service.ts 调用 request.get/post/... 新增 API 函数
keys.ts React Query 缓存键 新 query 的 key 枚举
request.ts axios 封装、鉴权 header 很少改
UI / Hook → data-service.ts（如 getStartupConfig） → api-endpoints.ts（如 config() → /api/config） → request.ts（axios + token） → Express route（如 api/server/routes/config.js） → 返回 JSON（形状应对齐 types）
改 types 后必须 rebuild：
npm run build:data-provider（仓库根目录）

样本链路：useGetStartupConfig → getStartupConfig → config() → GET /api/config
