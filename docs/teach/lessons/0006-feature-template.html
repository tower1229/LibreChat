本课只学一件事

前五课分别讲了地图、契约层、Hook、后端入口、消息流。本课把它们收成一张可复用的检查清单。

用仓库里真实的小功能 GET /api/banner（顶部公告条）走一遍完整链路 — 足够小，但覆盖了「types → endpoint → data-service → hook → UI → route → DB」全栈。

功能全景

Banner.tsx → useGetBannerQuery() client/data-provider/Misc/queries.ts → dataService.getBanner() packages/data-provider → GET /api/banner api-endpoints.ts → routes/banner.js optionalJwtAuth → getBanner(req.user) → data-schemas Banner.findOne({ displayFrom, displayTo, ... }) → MongoDB banners 集合

登录页和聊天页顶部都可能出现公告；未登录时仅展示 isPublic: true 的 banner。

12 步检查清单（只读 GET）

二开加类似 API 时，按此顺序改文件，减少返工：

#层文件做什么
1类型packages/data-provider/src/schemas.tstBannerSchema / TBanner
2类型packages/data-provider/src/types.tsTBannerResponse = TBanner | null
3路径api-endpoints.tsexport const banner = () => .../api/banner
4调用data-service.tsgetBanner(): request.get(endpoints.banner())
5缓存键keys.tsQueryKeys.banner = 'banner'
6构建项目根npm run build:data-provider
7DBpackages/data-schemas/src/methods/banner.tsgetBanner(user) — Mongo 查询
8路由api/server/routes/banner.js薄 handler，~15 行
9挂载routes/index.js + index.jsapp.use('/api/banner', routes.banner)
10Hookclient/src/data-provider/Misc/queries.tsuseGetBannerQuery
11导出client/src/data-provider/index.tsexport * from './Misc'
12UIclient/src/components/Banners/Banner.tsx消费 hook，渲染 HTML 公告
口诀：契约先行。先改 packages/data-provider，再动后端和前端。共享 types 变更后必须 npm run build:data-provider，否则 client/api 读到旧类型。

三层代码该写在哪

位置何时用Banner 里的例子
api/server/routes/*.jsHTTP 胶水：鉴权中间件 + 调服务 + 返回router.get('/', optionalJwtAuth, ...)
packages/data-schemasMongoDB model / methodcreateBannerMethods → Banner.findOne
packages/api复杂可复用 TS 逻辑、中间件、服务Banner 未用 — 简单查询不必进 api 包

规则来自 CLAUDE.md：新业务逻辑优先 packages/api；但一条 findOne 放在 data-schemas methods 里完全合理。

真实代码片段

契约层

// data-service.ts export function getBanner(): Promise<t.TBannerResponse> { return request.get(endpoints.banner()); }

Hook 层 — 注意 queriesEnabled 门控（登录流程完成前不发请求）：

// client/src/data-provider/Misc/queries.ts return useQuery<t.TBannerResponse>( [QueryKeys.banner], () => dataService.getBanner(), { refetchOnMount: false, enabled: ... && queriesEnabled }, );

薄路由

// api/server/routes/banner.js router.get('/', optionalJwtAuth, async (req, res) => { res.status(200).send(await getBanner(req.user)); });
