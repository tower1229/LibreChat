本课只学一件事

前三课你走完了前端链路。本课回答：HTTP 请求到达 Node 之后，谁先处理、路由怎么挂上、handler 写在哪？

入口文件是 api/server/index.js — legacy Express 服务，但它是整个后端的「总调度」。

参考：Express — Using middleware

两层后端，别混淆

层路径职责
Legacy 入口 api/server/ 启动、全局中间件、app.use 挂载路由、SPA fallback
新业务逻辑 packages/api（import 为 @librechat/api） TypeScript 服务、中间件、工具函数 — handler 调用它，不在这里堆路由
二开口诀：路由和薄 handler 留在 api/server/routes/；可复用业务逻辑写进 packages/api，再从 handler require('@librechat/api')。

两条时间线

新手常把「服务器启动时跑一次」和「每个请求都跑」混在一起。LibreChat 里要分清：

① 启动阶段 — startServer() 里，进程生命周期只执行一次：

connectDb() getAppConfig() ← 读 librechat.yaml / 环境变量 注册全局 app.use(...) ← 中间件 + 路由 app.listen(3080) → initializeMCPs() → checkMigrations() → serverReady = true ← 此时才接受聊天 POST

② 请求阶段 — 每次 HTTP 命中，按注册顺序穿过中间件链，最后落到某个 router.get/post/...。

健康检查：GET /health、/readyz 在路由挂载之前就注册了，不经过 API 中间件栈的完整路径。

全局中间件链（简化版）

在 index.js 里按顺序注册。顺序很重要 — 例如 express.json() 必须在需要读 body 的路由之前：

metricsMiddleware express.json / urlencoded mongoSanitize cors + cookieParser compression（可关） staticCache（dist / fonts / assets） passport.initialize + jwtLogin capabilityContextMiddleware ← 权限缓存，路由前必须有 ──────── 路由挂载区 ──────── /api/* → 各 feature Router apiNotFound（未匹配的 /api） SPA fallback（index.html） ErrorController（最后一个）

来源：api/server/index.js L152–279

路由挂载：三行模式

所有 REST 入口集中在 index.js 的「API Endpoints」区块。典型写法：

// ① 路由表聚合 const routes = require('./routes'); // → routes/index.js // ② 挂载：前缀 + 可选中间件 + Router app.use('/api/config', preAuthTenantMiddleware, optionalJwtAuth, routes.config); app.use('/api/messages', routes.messages); app.use('/api/agents/chat', rejectChatStartsUntilReady); // 单点门控 app.use('/api/agents', routes.agents);
部分含义
'/api/config'URL 前缀，与 data-provider 的 endpoints.config() 对齐
preAuthTenantMiddleware多租户：从 X-Tenant-Id 注入上下文（登录前路由也需要）
optionalJwtAuth有 JWT 则 req.user，没有也放行 — 同一 endpoint 登录前后响应不同
routes.configapi/server/routes/config.js 导出的 express.Router()

动手：本地看一眼启动日志

若 dev 环境已在跑，可跳过。否则在项目根目录：

npm run backend:dev

观察日志顺序：Connected to MongoDB → Server listening at http://localhost:3080 → Server readiness checks passing.

另开终端：curl -s http://localhost:3080/readyz — 启动完成前返回 NOT_READY，之后返回 OK。

场景改哪里
加新 REST 路径data-provider 契约 → routes/xxx.js handler → index.js 加一行 app.use
